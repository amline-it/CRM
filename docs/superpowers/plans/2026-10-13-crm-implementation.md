## تصمیم‌های فنی قطعی‌شده (بر پایه سنجش محیط)

| موضوع | تصمیم | چرا |
| --- | --- | --- |
| فریم‌ورک | Next.js 16 (App Router) + React 19 + TypeScript | آزمون‌شده در همین محیط؛ یک ریپو، پنل SSR + API |
| دیتابیس | **`node:sqlite` داخلی Node 22** پشت اینترفیس `Db` (لایه `src/db`) | Prisma به `binaries.prisma.sh` نیاز دارد که در محیط ساخت بسته است؛ صفر وابستگی باینری، WAL، مهاجرت SQL دست‌نویس، آداپتور Postgres در آینده با همان اینترفیس. Docker پین‌شده روی Node 24 |
| استایل | CSS سراسری RTL + توکن‌های رنگ (بدون Tailwind) | حذف ریسک بیلد، کنترل کامل RTL؛ فونت Vazirmatn از CDN مرورگر با fallback Tahoma |
| تاریخ | تبدیل جلالی با `Intl.DateTimeFormat('fa-IR-u-ca-persian')` | بدون وابستگی؛ ذخیره UTC، نمایش جلالی |
| احراز هویت | حساب محلی (scrypt + کوکی HttpOnly با `jose`) + SSO اختیاری JWT | مطابق پاسخ کارفرما (هر دو، قابل پیکربندی) |
| سینک | اینگست push/pull امضاشده HMAC + idempotency + وب‌هوک خروجی | مطابق پاسخ کارفرما |
| پرداخت/کد رهگیری/پیامک | آداپتور + پیاده‌سازی sandbox | تست‌پذیر بدون سرویس بیرونی |
| تست | Vitest — موتور، گاردها، افکت‌ها، سینک، احراز هویت + سناریوهای سرتاسری | هر گذار/گارد حداقل یک تست |
